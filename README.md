### 3. Olist E-Commerce Sales Analysis ⭐
End-to-end analysis of 99,441 real orders from Brazil's largest e-commerce marketplace. Covers revenue intelligence, customer cohort retention, CLV segmentation, seller performance, delivery delay analysis, and data quality auditing — with Python visualizations connected directly to PostgreSQL.

**Stack:** PostgreSQL 16, Python, pandas, matplotlib, seaborn, psycopg2

**Key Findings:**
- Less than 1% of customers return after their first purchase
- One week of delivery delay cuts review scores from 4.29 → 2.68
- Northern states average 22-29 day delays in top revenue categories

**Skills:** Window Functions, CTEs, Cohort Analysis, CLV Segmentation, Null Audit, Data Inconsistency Detection, Python Visualization
